# 符文旅人 · RUNE TRAVELER

一个可玩的编程 RPG 序章：在原创 2.5D 像素森林中，用真正的 Python 控制角色、点灯、驱散影兽和启动机关。

## 运行

需要 Node.js。首次下载项目后：

```sh
npm install
npm start
```

打开 http://127.0.0.1:4174 。当前工作区已安装依赖，可以直接 `npm start`。

**请通过本地服务打开，而不是双击 HTML**：Python 的 Web Worker 和 WebAssembly 需要 HTTP。安装完成后运行游戏不需要联网，界面、场景和 Python 都在本地。服务仅监听本机回环地址。

## 本版内容

- 8 个递进任务：输出、顺序执行、变量、循环、条件、函数、列表、综合挑战。
- CPython 3.14.2 / Pyodide 314.0.7，通过独立 Web Worker 执行真实 Python。
- 代码语法高亮、Tab 缩进、回车自动缩进、Ctrl / Cmd + Enter 运行。
- 逐动作回放、当前代码行高亮、可停止执行、错误行号及运行输出。
- 原创 Canvas 立体地形、像素建筑、林木、溪流、角色、光效与粒子。
- 任务奖励、经验等级、关卡解锁、知识手册、纪念品行囊。
- 每关代码自动保存，存档导入/导出、重开、环境音与减少动态效果选项。
- 桌面双栏和手机单栏布局。

## 使用方式

先阅读任务故事和目标，在右侧编辑代码并点击「运行代码」。第一关已提供可运行的例子，之后需要自己补全。遇到困难可查看「知识提示」或「旅人手册」。点击 ▷ 会先计算代码，然后逐步回放游戏动作；点击「连续执行」恢复自动回放。

每次运行都会重置本关场景。可重复挑战已完成的任务，奖励不会重复领取。存档保存在当前浏览器及访问地址下，localhost 和 127.0.0.1 的存档相互独立。

## 当前边界

这是包含两章及终章的可玩序章，不是完整商业 RPG。当前 8 关共用一张森林村落场景，随任务变化的机关、角色行为、光效及目标各不相同。场景由 Canvas 原创绘制，采用等距投影与像素精灵，不包含真正的 3D 网格、GPU 后处理或《歧路旅人 II》素材。真正 HD-2D 的美术资产、更多地区、战斗数值及完整课程可在这个基础上扩展。

Python 在本地 Worker 中运行，执行后回放动作；不是逐语句实时调试器。设置有 8 秒超时、12,000 行追踪步数和 180 个动作上限。没有交互式 input() 和第三方 Python 包安装入口。Worker 用于隔离 UI 与计算负载，不宣称是可安全执行不可信代码的安全沙箱。
