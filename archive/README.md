# 星际游隼 · STARFALL

一个纯 HTML、CSS、JavaScript 编写的太空躲避小游戏，无需安装依赖或构建。

## 开始游戏

双击 `index.html`，用浏览器打开即可游玩。字体不可联网加载时会自动使用系统字体，不影响游戏。

## 操作与规则

- 方向键左右 / A、D：移动飞船。
- 手机：在游戏区域按住并拖动。
- P：暂停或继续；切换窗口时自动暂停。
- 空格：开始、继续或重新开始。
- 收集金色星能，每颗 100 分；存活每秒获得 8 分。
- 飞船有三格护盾，受击后获得短暂无敌。
- 每 20 秒进入下一星区，陨石逐渐加速、增多。
- 最高分保存在当前浏览器本地。

## 文件

- `index.html`：页面与游戏界面。
- `style.css`：自适应布局与视觉样式。
- `game.js`：Canvas 绘制、碰撞、计分和输入处理。
